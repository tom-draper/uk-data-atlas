# UK Data Atlas

The geography resolver combines official boundary releases with curated named places.

## Language

**Named location**:
A stable, human-facing place identity whose membership can change over time.
_Avoid_: location definition

**Membership assertion**:
A source area code associated with a named location for a half-open effective interval.
_Avoid_: location member, member code

**Definition revision**:
A versioned set of membership assertions for a named location.
_Avoid_: location, member list
