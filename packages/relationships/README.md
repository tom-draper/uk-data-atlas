# @uk-data-atlas/relationships

Crosswalks between areas and translation of values across them. Import from `@uk-data-atlas/relationships`. The package includes crosswalk readers, relationship paths, validation and member reconciliation. It also holds the lineage and capability resolvers, area absence explanations, relationship repair reports (`RelationshipRepairSource`) and area validation (`AreaValidationSource`), each over a small interface that `atlas-loader` satisfies.
